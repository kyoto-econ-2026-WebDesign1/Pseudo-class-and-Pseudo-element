# 擬似クラスと擬似要素の練習

このプロジェクトは、CSSの**擬似クラス**と**擬似要素**を学習・練習するためのサンプルサイトです。

## 📚 学習内容

### 擬似クラス（Pseudo-class）

擬似クラスは、要素の特定の状態を選択するために使用します。コロン（`:`）で始まります。

#### `:hover` - マウスオーバー時のスタイル

要素にマウスを乗せたときのスタイルを指定します。

**使用例（4箇所）：**

1. **ロゴリンクの色変更**
   ```css
   header h1 a:hover {
       color: #1d4ed8;
   }
   ```
   - マウスを乗せると、ロゴリンクの色が濃い青に変わります

2. **ナビゲーションリンクの背景色と文字色変更**
   ```css
   header nav a:hover {
       color: #fff;
       background-color: #3b82f6;
   }
   ```
   - マウスを乗せると、ナビゲーションリンクの背景が青くなり、文字が白に変わります

3. **カードの影を濃くする**
   ```css
   .service__card:hover {
       box-shadow: 0 4px 8px rgba(0, 0, 0, 0.15);
   }
   ```
   - マウスを乗せると、カードの影が濃くなります

4. **フッターリンクの色変更**
   ```css
   footer nav a:hover {
       color: #60a5fa;
   }
   ```
   - マウスを乗せると、フッターリンクの色が明るい青に変わります

---

### 擬似要素（Pseudo-element）

擬似要素は、要素の特定の部分にスタイルを適用するために使用します。ダブルコロン（`::`）で始まります。

#### `::before` - 要素の前にコンテンツを追加

要素の**前**にコンテンツを追加します。

**使用例：**

```css
.service h3::before {
    content: "★";
    color: #3b82f6;
    margin-right: 8px;
}
```
- 「事業内容」というタイトルの**前**に星マーク（★）が表示されます
- `content`プロパティで追加する内容を指定します

#### `::after` - 要素の後にコンテンツを追加

要素の**後**にコンテンツを追加します。

**使用例（3箇所）：**

1. **タイトルの後に記号を追加**
   ```css
   .about h3::after {
       content: "【company information】";
       color: #3b82f6;
       font-size: 16px;
       margin-left: 8px;
   }
   ```
   - 「会社概要」というタイトルの**後**に「【company information】」が表示されます

2. **タイトルの後に記号を追加**
   ```css
   .service h3::after {
       content: "★";
       color: #3b82f6;
       margin-left: 8px;
   }
   ```
   - 「事業内容」というタイトルの**後**に星マーク（★）が表示されます

3. **カードタイトルの後に記号を追加（hover時に表示）**
   ```css
   .service__card h4::after {
       content: "";
       color: #3b82f6;
       opacity: 0;
       transition: opacity 0.3s;
   }
   
   .service__card:hover h4::after {
       content: " →";
       opacity: 1;
   }
   ```
   - 通常は非表示（`opacity: 0`）
   - カードにマウスを乗せると、タイトルの**後**に矢印（→）が表示されます

## 🔗 擬似クラスと擬似要素の組み合わせ

擬似クラスと擬似要素を組み合わせて使用することもできます。

**使用例：**

```css
.service__card:hover h4::after {
    content: " →";
    opacity: 1;
}
```

- `.service__card:hover` - カードにマウスを乗せたとき
- `h4::after` - h4要素の後に追加するコンテンツ
- つまり、「カードにマウスを乗せたとき、h4の後に矢印を表示する」という意味です

## 📝 まとめ

### 擬似クラス `:hover` の特徴
- マウスを要素の上に乗せたときのスタイルを指定
- インタラクティブな要素（リンク、ボタンなど）によく使用
- ユーザーに「クリックできる」ことを視覚的に示す

### 擬似要素 `::before` と `::after` の特徴
- HTMLを変更せずに、要素の前後にコンテンツを追加できる
- `content`プロパティで追加する内容を指定（必須）
- 装飾的な記号やテキストを追加するのに便利

### 使い分け
- **擬似クラス**：要素の状態（hover、active、focusなど）を表現
- **擬似要素**：要素の特定の部分（前、後、最初の行など）にスタイルを適用
